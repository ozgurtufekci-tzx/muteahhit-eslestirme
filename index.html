GitHub’a bağlan

Kayıtlar GitHub’daki gizli muteahhit-veri deposunda duruyor. Bu cihazda görmek ve düzenlemek için GitHub anahtarını bir kez girin; tarayıcı hatırlar.

  1. Yeni anahtar sayfasını açın (GitHub’a giriş yapmış olmalısınız).
  2. Token name: muteahhit. Expiration: istediğiniz kadar uzun bir süre.
  3. Repository access: Only select repositories, listeden muteahhit-veri.
  4. Permissions bölümünde Contents için Read and write seçin.
  5. Generate token deyin, çıkan anahtarı kopyalayıp aşağıya yapıştırın.
