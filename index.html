Düzenleme için bağlan

Listeyi görmek için giriş gerekmez. Kayıt eklemek, bölge girmek ya da silmek istersen bu cihazda bir kez GitHub anahtarı gir; tarayıcı hatırlar.

  1. Yeni anahtar sayfasını aç (GitHub’a giriş yapmış olmalısın).
  2. Token name: muteahhit-duzenle. Expiration: hazır seçeneklerden biri (örneğin 1 yıl).
  3. Repository access: Only select repositories, listeden muteahhit-eslestirme.
  4. Permissions bölümünde Contents için Read and write seç.
  5. Generate token de, çıkan anahtarı kopyalayıp aşağıya yapıştır.
