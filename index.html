Bu sayfa henüz kurulmamış. Bir kez, admin olarak kurman gerekiyor. Sayfanın kayıtları kaydedebilmesi için bir GitHub anahtarı lazım; anahtar sayfada şifrelenip saklanır, kullanıcılar onu hiç görmez.

  1. Yeni anahtar sayfasını aç (GitHub’a giriş yapmış olmalısın).
  2. Token name: muteahhit. Expiration: en uzun süreyi seç.
  3. Repository access: Only select repositories, listeden muteahhit-eslestirme.
  4. Permissions bölümünde Contents için Read and write.
  5. Generate token de, çıkan anahtarı kopyalayıp aşağıya yapıştır.
